Architecture decisions

The same hours.
Two ways to inspect them.

Reconciliation invariant

Organization and initiative views must reconcile to a zero-hour delta for each modeled week. This protects against conflicting executive totals.

View-scoped filtering

A filtered detail view does not silently change portfolio-wide headline figures. Scope labels explain the difference.

Portable delivery

A self-contained HTML prototype supports stakeholder review without a backend. Hash navigation supports local-file use.

Honest approximation

Where initiative-level weekly actuals are absent, proportional allocations remain labeled estimates. A reconciled estimate is still an estimate.

AI architecture · Decisions and safeguards

Explain the numbers.
Keep people in control.

A convincing explanation is only useful when its facts are trustworthy. Atlas separates source records, capacity calculations, AI explanations, and human decisions. The workflow document defines the controls below; the review prototype illustrates the experience with sample data.

Start with trusted records

Read permitted Monday.com fields through a defined refresh contract. Keep record references, calculation methods, and last-refreshed times attached so a reviewer can trace the answer.

Calculate first. Explain second.

Use application calculations for hours and capacity totals. AI explains the result and proposes options. Historical-pattern predictions remain distinguishable from actuals and carry model and confidence information.

Enforce the action boundary

The documented architecture gives the agent read-only tools, enforced in code. It can query and explain; it has no source-system write tools. Executives test scenarios in Atlas and make plan changes in Monday.com.

Make uncertainty visible

Expose stale records, missing hours, low confidence, and totals that do not reconcile. A flagged gap prompts investigation. Keep AI outputs connected to their inputs and model version in the audit history.

Architecture basis: Atlas Automation, AI & Workflows. Model/provider choices, live enforcement tests, prediction accuracy, response times, and operating costs are not established by the supplied feature description.
