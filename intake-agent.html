AI architecture · Decisions and safeguards

Check the request.
Explain the next step.

The Intake Agent is a separate application shown through a local design example. It demonstrates a clear split between required-field checks, permitted context, AI-assisted interpretation, and the IT Demand decision.

Use rules for required information

Check whether the request has the business need, owner, scope, and expected outcome. A fluent summary must not hide missing information.

Retrieve only permitted context

Use structured records for exact facts and approved documents for policy context. Apply access checks before retrieval and keep source references with the draft.

Keep routing accountable

Draft clarification questions and a routing suggestion. IT Demand confirms readiness. The portfolio simulation has no live model, source writes, or automated approval.

Basis: the Intake Agent workflow design and three synthetic portfolio scenarios. Live permission enforcement, model behavior, integration failures, and measured business outcomes require a connected implementation.

My contribution and the implementation evidence

My documented design focus is clarification, completeness rules, context boundaries, draft recommendations, and the human review experience. The three sample scenarios demonstrate those decisions; they do not establish a production model integration or backend implementation.

A deeper technical review should connect these decisions to the system diagram, implementation owners, access and tool configuration, and recorded evaluation results. Model choice, measured quality, response time, and operating cost should be stated when verified.

Product judgment

Rules for completeness.
Reasoning for context.

The design separates predictable validation from interpretation. Missing fields produce clarification requests; restricted context remains outside the response; recommendations remain drafts until reviewed. Shared sources such as Monday.com or SharePoint are contextual design references, not evidence that this application shares a deployment with Atlas or IT Intelligence.
