# Charious McLaurin — Portfolio

Portfolio website for Charious McLaurin: AI product architecture, product management, UX architecture, and selected Nightingale College work.

## Run locally

The site is plain HTML, CSS, and JavaScript with no build step. From the repository root run:

```sh
python3 -m http.server 8000
```

Open http://localhost:8000.

## Deploy to Hostinger

Upload the repository contents to the website document root (typically `public_html`). Keep `index.html` and `.htaccess` at the root and preserve the `assets` folder. The included Apache configuration supports extensionless URLs such as `/it-intelligence`.
